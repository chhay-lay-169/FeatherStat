# FeatherStat

A featherweight (~16 MB RAM) macOS menu bar resource monitor.

## Features
- Ultra-low RAM footprint: Direct kernel host_statistics64, sysctl, and IOKit calls.
- Modules: RAM, Network I/O, CPU, and GPU.
- Refresh rates: 1s, 2s, 3s.

## Build from Source
```bash
./build.sh
```
